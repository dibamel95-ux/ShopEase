# 🛍️ ShopEase – E-commerce Web Application
## 📖 Overview
ShopEase is a responsive e-commerce web application built with HTML, CSS, and JavaScript. The application allows users to browse products, search, filter, manage a shopping cart, and authenticate using a login and registration system.

## ✨ Features
* User Registration & Login
* Product Listing
* Product Details Page
* Search Products
* Filter by Category
* Sort by Price
* Shopping Cart Management
* Quantity Update
* LocalStorage Persistence
* Responsive Design

## 🛠️ Technologies Used
* HTML5
* CSS3
* JavaScript (ES6+)
* Fetch API
* LocalStorage
* Font Awesome

## 🌐 APIs
* **DummyJSON API** – Product catalog and product details.
* **MockAPI** – User authentication (Login & Registration).
